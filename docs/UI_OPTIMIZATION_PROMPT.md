# WinDrop 配对与设置窗口 UI 诊断及优化提示词

## 一、从运行截图诊断出的 7 个界面问题

基于实际运行截图分析，当前 `PairingAndSettingsWindow` 存在以下影响视觉美观与完整展示的布局和控件样式问题：

1. **窗口高度固定且偏小，底部状态提示被严重截断**
   - 窗口此前写死 `Height = 675` 且不可调整大小，底部 `_statusLabel` 仅露出最上方几个像素，网络自检提示与保存反馈完全无法看清。
2. **底部三按钮右侧宽度偏窄，按钮文字发生裁切**
   - “🛡️ 一键放行防火墙”因与另外两个按钮并列且水平内边距较大，导致末尾“墙”字被切掉一半。
3. **网卡选择下拉框（`_nicComboBox`）样式割裂且推荐文本被截断**
   - 原生 WPF `ComboBox` 在深色背景下仍使用浅灰 Aero2 主题边框与白底展开列表，与 `#0F172A` / `#1E293B` 深色卡片严重冲突；同时“自动智能优选（当前推荐：192.168.0.139 · 已过滤 2 个虚拟网卡）”文本过长，未展开时在右侧直接被截断成 `…已过`。
4. **基础输入控件缺乏现代圆角与深色统一质感**
   - `TextBox`、`Button` 多为尖角矩形；`CheckBox` 仍使用传统灰白方框，整体偏早期 Win32 风格，缺乏一致的悬浮/聚焦/按下微交互。
   - Bark 区域中的“唤醒快捷指令名(拆分版填 从电脑接收):”标签过长，严重挤压了右侧 `_shortcutNameBox` 的输入空间；下方复选框文案“推送文本/网址时附带内容（支持下拉一键复制或直开网页）”贴近右卡片边缘。
5. **系统顶部标题栏与深色主体反差刺眼**
   - Windows 原生标题栏默认白底黑字，与主体深蓝黑背景形成强烈割裂。
6. **左侧扫码卡片上下留白过多，信息利用不充分**
   - 左侧二维码卡片缺少当前运行状态胶囊（服务状态、端口、已屏蔽虚拟网卡数量）和“浏览器直接打开配置引导页”快捷入口。
7. **右侧设置区缺少滚动保护机制**
   - 当系统启用 125% 或 150% DPI 缩放时，固定垂直堆叠极易再次把底部按钮或状态栏顶出可视区域。

## 二、UI 优化修改提示词（可直接复用）

> **提示词正文：**
>
> 请重构 `src/WinDrop.App/Views/PairingAndSettingsWindow.cs`，在 **100% 保留现有全部配置项、数据读取/保存逻辑、网络自检、网卡切换、Bark 推送测试、防火墙放行、开机自启与右键菜单集成功能** 的前提下，全面升级窗口视觉与自适应布局：
>
> 1. **窗口骨架与深色标题栏**：
>    - 调整默认窗口尺寸为 `850 × 720`，设置 `MinWidth = 800`、`MinHeight = 640`，启用 `ResizeMode = ResizeMode.CanResizeWithGrip` 以便高 DPI 下自由拉伸。
>    - 全局字体统一为 `Microsoft YaHei UI`。
>    - 在 `SourceInitialized` 阶段通过 `dwmapi.dll` 的 `DwmSetWindowAttribute`（优先尝试属性 `20`，回退 `19`）启用 Windows 11/10 原生沉浸式深色标题栏。
> 2. **统一深色圆角控件样式体系**：
>    - 通过 `XamlReader.Parse` 向窗口 `Resources.MergedDictionaries` 注入标准 WPF 样式：`DarkButtonStyle`（圆角 `6`、Hover/Pressed 交互过渡）、`DarkTextBoxStyle`（圆角 `6`、深色背景 `#0B1220`、聚焦高亮边框 `#38BDF8`）、`DarkComboBoxStyle` 与 `DarkComboBoxItemStyle`（深色下拉框本体、自定义箭头、深色圆角弹出菜单与 Hover 高亮）、`DarkCheckBoxStyle`（深色圆角复选框与蓝底白钩视觉）。
> 3. **左侧扫码配对卡片增强**：
>    - 在二维码与 `/setup` 地址说明下方新增实时状态胶囊，展示绿色运行指示圆点、当前监听端口，以及自动过滤的虚拟/TUN 网卡数量。
>    - 新增“🌐 浏览器打开引导页”按钮，一键用系统默认浏览器打开 `http://{SelectedIp}:{Port}/setup`。
> 4. **右侧三段式自适应布局与高 DPI 防裁切**：
>    - 右侧容器改用三行 `Grid`：顶部固定标题区（`Auto`）、中间带 `ScrollViewer`（`VerticalScrollBarVisibility="Auto"`）的参数设置区（`*`）、底部固定操作区（`Auto`）。
>    - 精简网卡下拉框文案（默认项改为 `自动优选（当前：192.168.x.x）`，列表项改为 `192.168.x.x · 分类 (接口名)`），防止长文本在未展开时被截断。
>    - 将 Bark 行的“唤醒快捷指令名:”标签缩短并把原括号说明移入 `ToolTip`，确保右侧输入框宽度充裕；调整下方复选框文案间距避免贴边。
>    - 底部三个操作按钮统一采用均分三列布局，文字简化为“🛡️ 放行防火墙”、“🔍 联机自检”、“💾 保存设置”，保证任何缩放比例下均不裁切；按钮下方预留可自动换行的两行高 `_statusLabel`，确保完整展示状态与诊断反馈。
