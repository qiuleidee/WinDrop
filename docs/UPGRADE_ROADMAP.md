# WinDrop 进阶优化与升级路线图（Upgrade Roadmap）

本文档记录 WinDrop 在基础版（右键/复制 ⇄ 官方快捷指令互通）之上的 **6 大核心体验与工程升级计划**，按顺序逐项开发、测试与交付。

| 序号 | 升级模块名称 | 核心解决痛点 | 当前状态 |
| :---: | :--- | :--- | :---: |
| **#1** | **电脑主动推送 → iPhone 弹窗一键接收闭环** | 解决电脑点右键分享或复制后，还需手动划开手机控制中心去点接收的“半被动”割裂感 | ✅ 已完成 |
| **#2** | **拆分版专属官方签名快捷指令（零菜单直达）** | 消除二合一快捷指令每次手动触发时的 `Send / Receive` 选择菜单，支持照片直存相册、文档直存文件 | ✅ 已完成 |
| **#3** | **大文件实时传输进度浮窗与托盘最近记录** | 传输数百 MB / 数 GB 的 4K 视频时实时展示百分比与网速，托盘随时回看最近 10 条记录 | ⏳ 待开始 |
| **#4** | **右键分享整个文件夹时自动流式打包 ZIP** | 支持包含多级子目录的文件夹一键完整保持目录结构传至 iPhone「文件」App 解压 | ⏳ 待开始 |
| **#5** | **托盘一键开启本地直连热点与多网卡绑定切换** | 应对校园网/酒店 AP 隔离、户外高铁无路由器及办公双网卡（内网网线 + 外网 Wi-Fi）场景 | ⏳ 待开始 |
| **#6** | **单文件免环境 `.exe` 打包与 Win11 一级右键菜单** | 生成无需安装 .NET 运行时的独立单文件程序，并适配 Windows 11 新版一级右键菜单 | ⏳ 待开始 |

## 各升级项详细技术规格

### 升级项 #1：电脑主动推送 → iPhone 弹窗一键接收闭环
- **触发时机（零打扰日常普通复制）**：
  1. 用户在资源管理器选中文件/文件夹点击 **右键「通过 WinDrop 分享」** 时，自动向 iPhone 发送推送横幅；
  2. 用户在电脑复制了文字/网址/截图/文件后，按下全局热键 **`Ctrl + Shift + D`** 或点击托盘菜单 **「📲 推送当前剪贴板并通知 iPhone」** 时，主动向 iPhone 发送推送横幅。
- **推送通道（Bark APNs 协议，支持官方与自建服务器）**：
  - 智能解析用户粘贴的纯 `Bark Key`、完整示例链接（`https://api.day.app/<key>/...`）或私有自建服务器地址。
  - 通知自带跳转 Scheme：`shortcuts://run-shortcut?name=<快捷指令名称>`，用户在 iPhone 锁屏或顶部横幅**轻点一下通知即自动拉起快捷指令完成文件/剪贴板接收**。
  - **隐私保护**：文件内容 100% 留在局域网直传，绝不经过推送服务器；剪贴板文本默认仅发唤醒提醒（可选开启短文本/URL 随通知一键复制或直开）。
- **可视化配置**：在设置窗口提供「Bark Key 或地址」输入、「唤醒快捷指令名称」设置及 **「🔔 测试推送」** 实时验证按钮。

### 升级项 #2：拆分版专属快捷指令与智能归档
- 将「共享表单发送到电脑」与「一键无菜单从电脑接收（自动区分图片存相册、视频存相册、文档存文件、文本入剪贴板）」拆分为独立流程，支持绑定操作按钮与轻点背面。

### 升级项 #3：大文件实时进度浮窗与托盘历史子菜单
- 上传/下载大文件（> 10MB）时在右下角展示平滑进度条、百分比与瞬时 `MB/s` 速率；系统托盘维护最近 10 条收发历史，点击即可直接打开或重新复制。

### 升级项 #4：多文件与多级文件夹自动流式 ZIP 归档
- 右键选中含子目录的文件夹时，流式生成临时归档（完整保留相对路径树）供 iPhone 一次拉取，避免手机连续弹出几十次单文件保存提示。

### 升级项 #5：无路由器本地热点一键开关与网卡选择器
- 托盘与设置窗集成 WinRT 移动热点 / Wi-Fi Direct Legacy AP 开关（附 `WIFI:` 扫码直连二维码），并支持手动锁定指定物理网卡 IP。

### 升级项 #6：单文件独立 EXE 发布与 Windows 11 一级右键支持
- 提供单文件自包含发布脚本（`PublishSingleFile`）及现代 Windows 11 右键扩展适配。
