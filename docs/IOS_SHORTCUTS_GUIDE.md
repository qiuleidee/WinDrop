# iPhone 成品快捷指令一键安装与使用指南

WinDrop 已直接适配 **Apple 官方 iCloud 公证签名的成品快捷指令**，你**无需自己手动编写任何动作步骤**，直接扫码添加即可使用！

---

## 第一步：一键添加成品快捷指令（仅首次需要，耗时 20 秒）

1. 在电脑上双击运行 [启动WinDrop.bat](../启动WinDrop.bat)（或 `dist\WinDrop\WinDrop.exe`），弹出 **「WinDrop — iPhone 快捷指令配对与设置」** 窗口（如果首次弹出 Windows 防火墙提示，请勾选「专用网络 + 公用网络」并允许访问，或点击窗口里的 **「🛡️ 一键放行防火墙」**）。
2. 打开 iPhone 自带 **「相机」** 扫描窗口左侧的二维码，在 Safari 打开引导页：
   - 点击 **「第 1 步：点击获取并添加官方快捷指令」**（或直接在 iPhone Safari 打开成品链接：`https://www.icloud.com/shortcuts/c499c9a3d9b04e189cce38d9560b3e2e`；你也可以直接扫项目目录 `shortcuts/iPhone扫码安装官方快捷指令.png`）。
3. 点击页面上的 **「添加快捷指令」**，在配置框中粘贴电脑窗口（或手机引导页一键复制）显示的 3 项参数：
   - **host**：填写电脑窗口显示的 **`<本机计算机名>.local`**（程序自动读取你的 Windows 计算机名并通过内置 mDNS 广播，无需安装苹果 Bonjour；若计算机名含中文或路由器不支持 `.local`，可填窗口显示的备用局域网 IP）
   - **port**：填 `58446`（默认端口）
   - **key**：粘贴窗口显示的 6 位密钥
4. **必开设置（防止一次发多张照片时报错）**：
   - 打开 iPhone **「设置 → App → 快捷指令 → 高级」**，开启 **「允许共享大量数据」**。
5. **推荐便捷入口**：
   - 打开 iPhone **控制中心**（右上角下滑）→ 长按空白处添加控制项 → 搜索「快捷指令」→ 选择刚添加的快捷指令！这样随时下滑一下就能一键接收电脑文件！

## 第二步：日常极简互传操作

### 1. iPhone 发送到 Windows（通过「共享表单」自动静默发送）
- **发原图 / 视频 / 任意文件**：在 iPhone 相册、文件、微信或 Safari 中选中 1 个或多个文件 → 点击系统 **「分享」** → 在共享表单里点一下该快捷指令（首次提示网络权限点「始终允许」）。
  - **效果**：文件原画质自动流式保存到电脑 `Downloads\WinDrop` 目录，电脑右下角弹出轻通知（可直接点 **「打开文件」「定位目录」「复制文件」**）。
- **发文字 / 剪贴板**：在手机复制文字后运行快捷指令点 **Send**，文字自动进入电脑剪贴板，电脑直接按 `Ctrl + V` 粘贴！

### 2. Windows 发送到 iPhone（通过「右键分享」或「Ctrl+C 复制」，手机快捷指令接收）
在 Windows 电脑上，你只需做以下任意一个习惯动作：
- **动作 A（右键分享）**：在资源管理器选中单个或多个文件/文件夹 → 右键点击 **「通过 WinDrop 分享」**；
- **动作 B（直接复制）**：对任意文件按 `Ctrl + C` 复制，或对一段文字/网址按 `Ctrl + C`，或用 `Win + Shift + S` 截一张图；

然后拿起 iPhone，在控制中心（或桌面/轻点背面）点一下快捷指令并选择 **Receive（接收）**：
- 若电脑复制/右键分享的是 **文件 / 照片 / 视频**：自动批量拉取到 iPhone 保存！
- 若电脑复制的是 **截图 / 图片**：自动传到 iPhone！
- 若电脑复制的是 **文字 / 链接**：自动写入 iPhone 剪贴板，直接粘贴！

## 第三步（强烈推荐）：开启电脑主动推送，iPhone 锁屏弹窗轻点即收

如果你希望**电脑一点右键分享，手机立刻“叮”一声弹出通知，点一下通知就自动开始接收**：

1. 在 iPhone App Store 搜索并安装免费开源的 **「Bark」** 通知工具（打开后允许通知权限，首页即可看到你的专属推送 Key 或链接）。
2. 打开电脑端 WinDrop 设置窗口，在底部 **「🔔 iPhone 主动推送唤醒」** 区域：
   - 粘贴你的 **Bark Key 或完整链接**（例如 `AbCdEf123456` 或 `https://api.day.app/AbCdEf123456/...`）；
   - 确认「唤醒快捷指令名称」与手机里安装的快捷指令名称一致（默认 `AirDrop Plus`）；
   - 点击 **「🔔 测试推送」**，iPhone 收到通知且点开能唤起快捷指令即配置完成！
3. **日常体验**：以后无论是在资源管理器对文件点 **右键「通过 WinDrop 分享」**，还是复制完文字/截图后按 **`Ctrl + Shift + D`**，iPhone 都会瞬间收到顶部横幅提醒，轻点横幅直接拉取文件！
   - *注：文件内容依然 100% 走局域网直传，绝不经过推送服务器；剪贴板文本默认仅发唤醒通知，保护隐私。*

## 第四步（升级项 #2）：零菜单拆分版快捷指令（推荐绑定操作按钮 / 轻点背面）

如果你希望彻底告别 `Send / Receive` 二选一菜单，实现：
- **「发送到电脑」**：共享表单点一下直接发，无任何弹窗菜单；
- **「从电脑接收」**：点一下（或轻点 Bark 推送通知）自动智能分流——**照片/视频直接存进系统相册、文档存进「文件」App、网址直接 Safari 打开、文字自动写入手机剪贴板**。

### 方式 A：在手机「快捷指令」App 三步极简自建（30 秒，立即可用）
扫码打开电脑引导页（`http://<电脑IP>:58446/setup`）最下方的 **「⚡ 进阶：零菜单拆分版快捷指令」** 卡片，一键复制对应地址：

1. **新建「发送到电脑」**：
   - 打开「快捷指令」→ 点 `+` 改名为 `发送到电脑` → 底部 `ⓘ` 开启「在共享表单中显示」。
   - 添加 **「获取 URL 内容」** → 粘贴发送专线 `http://<电脑名>.local:58446/v2/send` → 方法 `POST` → 头部填 `Authorization: <密钥>` → 请求体选 **表单**，添加字段 `file`（类型文件）= 快捷指令输入。
   - （可选）添加「显示通知」显示「URL 的内容」，发送成功直接弹出电脑端回复！
2. **新建「从电脑接收」**（单文件/照片/文本零配置极简版）：
   - 打开「快捷指令」→ 点 `+` 改名为 `从电脑接收`。
   - 添加 **「获取 URL 内容」** → 粘贴接收专线 `http://<电脑名>.local:58446/v2/receive?direct=1` → 头部填 `Authorization: <密钥>`。
   - 紧接其后添加 **「存储到相簿」**（收照片/视频）或「快速查看 / 拷贝至剪贴板」，并把 WinDrop 设置里的「唤醒快捷指令名」改为 **`从电脑接收`**！

### 方式 B：用 Mac 或 GitHub Actions 签署完整五路智能归档 `.shortcut` 包
本项目已为你内置完整的拆分版动作流源码（`shortcuts/发送到电脑.shortcut` 与 `shortcuts/从电脑接收.shortcut`，内含 `url / text / image / video / file` 五路自动分支）：
- **有 Mac**：将 `shortcuts/` 拷贝到 Mac 运行 `bash sign_on_mac.sh`（调用 Apple 官方 `shortcuts sign --mode anyone`）即可生成可直接隔空投送导入任意 iPhone 的正式签名版。
- **无 Mac（免费云端签名）**：在你的 GitHub 仓库进入 **Actions → 「自动签署 WinDrop 拆分版 iOS 快捷指令」→ Run workflow**，即可免费由 GitHub `macos-latest` 云端调用 Apple 官方工具签好后下载导入！
