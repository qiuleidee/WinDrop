# iPhone 快捷指令安装与使用指南

WinDrop 已在仓库 `shortcuts/` 目录直接提供 **Apple 官方已签名的拆分版快捷指令**（`WinDrop发送_已签名.shortcut` 与 `WinDrop接收_已签名.shortcut`），添加到 iPhone 并按电脑端显示的参数修改地址和密钥即可立即使用！

---

## 第一步：添加已签名拆分版快捷指令（耗时 30 秒）

1. 在电脑上双击运行 [启动WinDrop.bat](../启动WinDrop.bat)（或 `dist\WinDrop\WinDrop.exe`），弹出 **「WinDrop — iPhone 快捷指令配对与设置」** 窗口（如果首次弹出 Windows 防火墙提示，请勾选「专用网络 + 公用网络」并允许访问，或点击窗口里的 **「🛡️ 一键放行防火墙」**）。
2. 将仓库中的两份已签名快捷指令导入你的 iPhone：
   - [WinDrop发送_已签名.shortcut](../shortcuts/WinDrop发送_已签名.shortcut)（共享表单多图/多文件自动循环发到电脑）
   - [WinDrop接收_已签名.shortcut](../shortcuts/WinDrop接收_已签名.shortcut)（零菜单一键从电脑接收并按格式智能归档）
3. 打开 iPhone 自带 **「相机」** 扫描电脑窗口左侧的二维码打开配置引导页，一键复制参数填入刚添加的两个快捷指令：
   - **发送指令**：将请求 URL 改为 `http://<本机计算机名>.local:58446/v2/send`，请求头 `Authorization` 改为你的密钥；
   - **接收指令**：将第 1 步请求 URL 改为 `http://<本机计算机名>.local:58446/v2/receive`，请求头 `Authorization` 改为你的密钥。
   - *注：若局域网路由器不支持 `.local`，可改填引导页显示的内网 IP 地址。*
4. **必开设置（防止一次发多张照片时报错）**：
   - 打开 iPhone **「设置 → App → 快捷指令 → 高级」**，开启 **「允许共享大量数据」**。
5. **推荐静默触发入口（不切屏进快捷指令主界面）**：
   - 打开 iPhone **「设置 → 辅助功能 → 触控 → 轻点背面 → 轻点两下」**（或 **控制中心 → 添加控制 → 运行快捷指令**），绑定你的接收快捷指令！以后随时点一下就在后台静默收完。

---

## 第二步：日常极简互传操作

### 1. iPhone 发送到 Windows（通过「共享表单」自动静默发送）
- **发原图 / 视频 / 任意文件**：在 iPhone 相册、文件、微信或 Safari 中选中 1 个或多个文件 → 点击系统 **「分享」** → 在共享表单里点一下该快捷指令（首次提示网络权限点「始终允许」）。
  - **效果**：文件原画质自动流式保存到电脑 `Downloads\WinDrop` 目录，电脑右下角弹出轻通知（可直接点 **「打开文件」「定位目录」「复制文件」**）。
- **发文字 / 剪贴板**：在手机复制文字后运行快捷指令点 **Send**，文字自动进入电脑剪贴板，电脑直接按 `Ctrl + V` 粘贴！

### 2. Windows 发送到 iPhone（通过「右键分享」或「Ctrl+C 复制」，手机快捷指令接收）
在 Windows 电脑上，你只需做以下任意一个习惯动作：
- **动作 A（右键分享）**：在资源管理器选中单个或多个文件/文件夹 → 右键点击 **「通过 WinDrop 分享」**；
- **动作 B（直接复制）**：对任意文件按 `Ctrl + C` 复制，或对一段文字/网址按 `Ctrl + C`，或用 `Win + Shift + S` 截一张图；

然后拿起 iPhone，在控制中心（或桌面/轻点背面）点一下快捷指令并选择 **Receive（接收）**：
- 若电脑复制/右键分享的是 **文件 / 照片 / 视频**：自动批量拉取到 iPhone 保存！
- 若电脑复制的是 **截图 / 图片**：自动传到 iPhone！
- 若电脑复制的是 **文字 / 链接**：自动写入 iPhone 剪贴板，直接粘贴！

## 第三步（强烈推荐）：开启电脑主动推送，iPhone 锁屏弹窗轻点即收

如果你希望**电脑一点右键分享，手机立刻“叮”一声弹出通知，点一下通知就自动开始接收**：

1. 在 iPhone App Store 搜索并安装免费开源的 **「Bark」** 通知工具（打开后允许通知权限，首页即可看到你的专属推送 Key 或链接）。
2. 打开电脑端 WinDrop 设置窗口，在底部 **「🔔 iPhone 主动推送唤醒」** 区域：
   - 粘贴你的 **Bark Key 或完整链接**（例如 `AbCdEf123456` 或 `https://api.day.app/AbCdEf123456/...`）；
   - 确认「唤醒快捷指令名称」与手机里安装的快捷指令名称一致（默认 `AirDrop Plus`）；
   - 点击 **「🔔 测试推送」**，iPhone 收到通知且点开能唤起快捷指令即配置完成！
3. **日常体验**：以后无论是在资源管理器对文件点 **右键「通过 WinDrop 分享」**，还是复制完文字/截图后按 **`Ctrl + Shift + D`**，iPhone 都会瞬间收到顶部横幅提醒，轻点横幅直接拉取文件！
   - *注：文件内容依然 100% 走局域网直传，绝不经过推送服务器；剪贴板文本默认仅发唤醒通知，保护隐私。*

## 第四步（升级项 #2）：零菜单拆分版快捷指令（推荐绑定操作按钮 / 轻点背面）

如果你希望彻底告别 `Send / Receive` 二选一菜单，实现：
- **「发送到电脑」**：共享表单点一下直接发，无任何弹窗菜单；
- **「从电脑接收」**：点一下（或轻点 Bark 推送通知）自动智能分流——**照片/视频直接存进系统相册、文档存进「文件」App、网址直接 Safari 打开、文字自动写入手机剪贴板**。

### 方式 A：在手机「快捷指令」App 极简自建（立即可用，官方签名零报错）
扫码打开电脑引导页（`http://<电脑IP>:58446/setup`）最下方的 **「⚡ 进阶：零菜单拆分版快捷指令」** 卡片，一键复制对应地址：

1. **新建「发送到电脑」（仅 3 个积木）**：
   - 打开「快捷指令」→ 点 `+` 改名为 `发送到电脑` → 底部 `ⓘ` 开启「在共享表单中显示」。
   - **① 重复每一项**：重复对象选 **快捷指令输入**。
   - **② 获取 URL 的内容**（拖入循环内）：粘贴 `http://<电脑名>.local:58446/v2/send` → 方法 `POST` → 头部填 `Authorization: <密钥>` → 请求体选 **表单**，添加字段 `file`（类型选 **文件**）= **重复项目**。
   - **③（可选）显示通知**（放到结束重复外）：显示上一步「URL 的内容」。
2. **新建「从电脑接收」（全能 14 积木单循环版，支持网址 / 文本 / 相册 / 文件全自动分流）**：
   - 打开「快捷指令」→ 点 `+` 改名为 `从电脑接收`（并记得把电脑端 WinDrop 的「唤醒快捷指令名」改为 `从电脑接收`）。
   - **① 获取 URL 的内容**：URL 填 `http://<电脑名>.local:58446/v2/receive`，方法 `GET`，头部填 `Authorization: <密钥>`。
   - **② 获取词典值**（重命名为 `action`）：获取 **URL 的内容** 的 `action` 值。
   - **③ 如果 `action` 是 `url`**：获取 **URL 的内容** 的 `text` → **打开 URL** → 结束如果。
   - **④ 如果 `action` 是 `text`**：获取 **URL 的内容** 的 `text` → **拷贝至剪贴板** → 结束如果。
   - **⑤ 获取词典值**：获取 **URL 的内容** 的 `urls` 值。
   - **⑥ 重复每一项**（循环上一步得到的 `urls`，当电脑发文字/网址时 `urls` 为空数组，会自动安全跳过）：
     - **获取 URL 的内容**：URL 填 **重复项目**（下载链接已自带临时凭证，无需额外请求头）。
     - **如果 `action` 是 `media`**：**存储到相册**（存入 **URL 的内容**，自动把照片/视频/截图存进系统相册）。
     - **否则**：**存储文件**（保存 **URL 的内容** 到 iCloud/我的 iPhone「文件」App）。
     - 结束如果
   - **结束重复**
   - **（可选）结尾提示**：获取 **URL 的内容** 的 `summary` → **显示通知**。
   - *搭好后长按快捷指令 → 共享 → 拷贝 iCloud 链接，即可得到由你自己的 Apple 账号官方签名的分享直链！*

### 方式 B：用已登录 iCloud 的 Mac 签署 `.shortcut` 包
> 注：Apple 官方命令行工具 `shortcuts sign --mode anyone` 强制要求当前 Mac 已登录 iCloud，因此免费的云端无头虚拟机无法完成签名。
- 如果你手头有已登录 iCloud 的 Mac：将 `shortcuts/` 拷贝到 Mac 运行 `bash sign_on_mac.sh`（先替换为自己的 `<电脑名>.local` 与密钥）即可生成带 Apple 签名的 `.shortcut` 文件。
